# Hope Burger · Landing page

Landing page da hamburgueria Hope Burger (João Pessoa - PB), feita em HTML, CSS e JavaScript puros, sem build.

## Como abrir

Abra o `index.html` no navegador ou publique a pasta em qualquer hospedagem estática (GitHub Pages, Netlify, Vercel).

## Estrutura

- `index.html`: página completa (estilos e scripts inline)
- `img/`: logo e fotos dos produtos

## Conteúdo

Cardápio, preços, horários e contatos vêm do site oficial de pedidos (hopeburger.com.br). As avaliações são trechos reais do Google (consultados em 25/11/2026). Os botões de Google Maps, Waze e Uber usam as coordenadas reais das três unidades.
